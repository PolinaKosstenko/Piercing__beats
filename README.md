# Piercing Beats

## Сюжет

### Акт 1: Пробуждение среди отчисленных

Главная героиня просыпается среди бездушных тел на 5 уровне D-Tower. Все вокруг, включая ее саму, имеют черно-белый цвет, будто из них "высосали всю жизнь". Единственное, что она помнит — неправильный ответ на экзамене.

**Ключевые события:**
- Нейро-интерфейс показывает дату: 01.06.2055
- Обнаружение карт памяти в висках погибших с сообщением: "Вы отчислены из ДВФУ"
- Нахождение черно-белой катаны — первого оружия героини
- Встреча с таинственным азиатским помощником, который объясняет:
  - Нахождение на 5 уровне D-Tower — месте "последних комиссий"
  - Необходимость двигаться только вверх
  - Существование неких "ЮШ" и "ВИ-ШРМИ" на нижних уровнях

### Акт 2: Путь к зачетам

Героиня должна выбраться с 5 уровня, сражаясь с FEFU-ботами с помощью катаны.

**Структура прохождения:**
- Каждый акт соответствует этажу (6, 7, 8, 9)
- На каждом уровне необходимо получить зачет по разным предметам
- Процесс получения зачета:
  1. Зачистка уровня от роботов
  2. Победа над преподавателем в бою
  3. Правильные ответы на викторину

**Кульминация:**
- Первый босс: Робот-Аксолотоль
- После победы: осознание ограниченного времени для сдачи 4 долгов
- Финал: героиня обретает цвет, но не получает общагу

**Локация и атмосфера:** ДВФУ, 5 этаж корпуса D, вечернее время, акцент на неоновом освещении.

## Игровые механики

### Основной геймплей

**Ритмичная боевая система:**
- Удары по противникам наносятся в ритм музыки
- При приближении врага появляются ритмичные круги для удара
- Круги располагаются на разных частях тела противника (голова, руки, грудь)
- Разные типы ударов (определенные джойстики)

### Игровые объекты

#### Игрок (`obj_player`)
**Компоненты:**
- `CharacterController` — физическое перемещение и коллизии
- `VRInputHandler` — обработка ввода с контроллеров
- `StealthController` — управление скрытностью и уровнем шума
- `HeldObjectHandler` — управление удерживаемыми предметами
- `Rigidbody` — физическое взаимодействие
- `Collider` — детекция столкновений
- `AudioEmitter` — генерация шумовых событий

**Состояния:** Idle, Walking, Running, Crouching, Grabbing, Throwing

**Ключевые взаимодействия:** Move(), Grab(), Release(), Throw(), Crouch()

**Состояния:** Idle, Consumed, Expired


### Система событий
Игрок генерирует события, на которые реагируют NPC и системы:
- `OnStep()`, `OnLanding()` — шумовые события
- `OnGrab()`, `OnRelease()`, `OnThrow()` — взаимодействие с предметами
- `OnCrouch()` — изменение скрытности
- `OnNoiseGenerated()`, `OnVisibilityChanged()` — уведомления для ИИ

### Интеграция систем
- `VRInputHandler` координирует управление и взаимодействие
- `StealthController` реагирует на все действия игрока
- `AudioEmitter` служит триггером для NPC поведения
- Гибкая система подписки на события для внешних систем

## Баланс и настройки

**Параметры для настройки:**
- Радиус и интенсивность шума
- Время расследования NPC
- Чувствительность камер
- Длительность эффектов зелий
- Сложность ритмичных последовательностей

**Дизайн уровней:** Постепенное усложнение с увеличением этажа, введение новых типов врагов и более сложных ритмических паттернов.
